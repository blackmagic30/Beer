# Venue Partner Demo Checklist

Use this when showing Pint Path to a bar owner, venue manager, or potential affiliate partner.

## 1. Public Product Story

- Open the public map and describe the product as “Melbourne’s verified beer price and happy-hour map.”
- Search for a venue, suburb, or beer.
- Show “Best options right now,” “Happy hour near me,” “Cheapest near me,” and “Recently verified near me.”
- Explain that unknown prices are never treated as cheap and are shown as “No verified price yet.”
- Open a venue card and point out confidence, last verified date, happy-hour status, distance, and update/report CTAs.

## 2. Data Contribution Flow

- Click “Update this venue” or open `/submit.html` with a venue selected.
- Show the easiest path: upload a menu, tap list, receipt, or happy-hour board photo.
- Show manual entry for beer prices and happy-hour details.
- Explain that community data stays pending until verified or approved.
- Explain that contributors can earn full map access by submitting useful verified data.

## 3. Invite-Only Venue Portal

- Open `/for-bars` and confirm it redirects to `/venue-portal`.
- Explain that venue-manager access is invite-only during beta:
  - keep prices and happy hours accurate
  - help nearby locals find the venue
  - reduce stale or wrong listings
  - access privacy-safe aggregate demand signals
- Explain that public self-claiming is disabled so random users cannot request access to venue tools.
- Explain that this does not start paid venue billing.

## 4. Admin Follow-Up

- Log in as admin and open `/admin.html`.
- Show the venue partner interest queue.
- Update outreach status if relevant.
- Assign a manager test user to a venue.
- Explain that admin controls who can access venue tools.

## 5. Venue Portal Demo

- Log in as the assigned venue-manager user.
- Open `/venue-portal`.
- Confirm only assigned venue(s) are shown.
- Show:
  - listing quality score
  - current verified prices
  - wrong-price reports
  - user requests
  - aggregate insights
  - update link for QR/signage use
- Submit a venue update and explain it goes to review by default.

## 6. Privacy And Safety Talking Points

- Venue insights are aggregated and privacy-safe.
- Bars cannot see individual user names, emails, exact locations, or click paths.
- Location is only used when a user chooses “Use my location.”
- The app does not continuously track users.
- Prices may change; users should check with the venue before ordering.
- Drink responsibly.

## 7. Not Live Yet

- No free beer redemption.
- No paid venue billing.
- No brewery dashboard.
- No ID verification.
- No push/email marketing.
- No individual user analytics for bars.

## 8. Best Next Ask

- Ask the venue manager whether they would keep happy hours, tap lists, and beer prices updated if given a simple portal.
- Ask what aggregate insights would actually help them.
- Ask whether a QR code near the bar/tap list would be useful for collecting menu photos and corrections.
